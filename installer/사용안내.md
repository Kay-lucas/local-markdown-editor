# 로컬 Markdown 에디터

## 설치 파일 하나로 시작하기

1. `LocalMarkdownEditor-Setup-1.1.0-x64.exe`를 내려받아 실행합니다.
2. 설치 화면에서 **다음 → 설치 → 마침**을 누릅니다.
3. 시작 메뉴의 **로컬 Markdown 에디터**를 실행합니다.

Windows x64 PC용입니다. Flutter 설치·회원 가입·추가 구성 요소 다운로드는 필요하지 않습니다. 필요한 실행 구성 요소를 설치 파일에 함께 담았습니다.

기본 설치 위치는 사용자 계정의 `%LOCALAPPDATA%/Programs/LocalMarkdownEditor`입니다. 관리자 권한을 요구하지 않으며 다른 프로그램의 시스템 DLL은 바꾸지 않습니다.

## 사용하기

- **Ctrl+O**: 내 컴퓨터의 `.md`·`.markdown` 파일 열기
- **Ctrl+S**: 저장
- **Ctrl+Shift+S**: 다른 이름으로 저장
- 왼쪽에 Markdown을 붙여 넣으면 오른쪽에 서식 있는 문서가 나옵니다.
- 오른쪽 문장을 직접 수정하면 왼쪽 원문도 바뀝니다. 툴바는 마지막으로 선택한 편집 영역에 적용됩니다.
- 표·코드·이미지 등은 원문 보존 블록으로 표시하며 왼쪽에서 수정합니다.
- 오른쪽 **미리보기 / 편집하기** 버튼으로 읽기 전용 보기와 문서 편집을 전환합니다.
- Ctrl+Z / Ctrl+Y는 두 편집 영역의 변경을 함께 취소·다시 실행합니다.
- 수정하지 않은 블록은 원문을 유지하며, 수정한 블록의 Markdown 기호·빈 줄은 정리될 수 있습니다.
- 오른쪽 위 테마 버튼으로 시스템·라이트·다크를 선택합니다.
- 시작 메뉴의 **예제 문서**에서 `시작하기.md`를 열어볼 수 있습니다.

## 제거하기

Windows의 **설정 → 앱 → 설치된 앱 → 로컬 Markdown 에디터 → 제거** 또는 시작 메뉴의 **제거**를 사용합니다.

앱 실행 파일은 제거하지만 Markdown 문서·예제 문서·테마 설정은 남겨둡니다. 예제를 편집한 내용도 재설치나 제거 과정에서 덮어쓰지 않습니다.

## 현재 확인 범위

자동 테스트 90개와 Windows 빌드가 통과했습니다. 설치·재설치·제거 및 문서 보존도 자동 검증했습니다. 실제 두벌식 한글 입력·파일 선택 창·150% 배율 등 일부 수동 확인은 남아 있습니다.

현재 설치 파일에는 배포자 코드 서명이 없습니다. Windows나 브라우저에서 경고가 표시될 수 있습니다. 배포 정보와 검증 결과는 저장소의 README와 verification/v1.1.0.md를 확인해 주세요.
