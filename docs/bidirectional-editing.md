# 양방향 편집 — v1.1.0

## 사용 흐름

1. 왼쪽 Markdown 원문에 문서를 붙여 넣거나 Ctrl+O로 파일을 연다.
2. 오른쪽 **문서 편집**에 제목·문단·목록 등 서식이 반영된다.
3. 오른쪽에서 내용을 수정하면 왼쪽 원문과 미저장 표시가 갱신된다.
4. Ctrl+S로 같은 `.md` 파일에 저장한다. 별도 전용 문서 형식은 만들지 않는다.

AI 변환이나 번역이 아니다. Markdown 기호를 서식으로 보여주고, 편집 결과를 다시 Markdown으로 표현한다. 이 과정은 전부 로컬에서 이루어진다.

## 지원 범위

| 항목 | 오른쪽 문서 편집 | 왼쪽 원문 / 미리보기 |
| --- | --- | --- |
| 본문, 제목 H1~H6 | 직접 입력·수정. 툴바는 H1~H3 제공 | 지원 |
| 굵게·기울임·취소선·인라인 코드 | 선택 후 툴바·단축키로 수정 | 지원 |
| 단순 글머리·번호 목록 | 직접 수정, Enter로 항목 추가 | 지원 |
| 체크리스트 | 문구 수정·체크 변경 | 지원 |
| 단순 인용문·HTTP(S) 링크 | 직접 수정·링크 삽입 | 지원 |
| 표·코드 블록·이미지·구분선 | 원문 보존 블록으로 표시. 내부 수정은 왼쪽에서 수행 | 지원 |
| 복잡한 중첩 목록·중첩 인용·명시적 강제 줄바꿈 등 | 지원 범위를 벗어나면 원문 보존 블록으로 표시 | 원문에서 수정 |
| 원시 HTML | 원문을 보존하고 문자로 표시, 실행하지 않음 | 문자로 표시 |
| 색상·밑줄·임의 글꼴·워드 문서 서식 | Markdown에 없는 서식은 제공하지 않음 | 해당 없음 |

오른쪽의 **미리보기** 버튼은 기존 읽기 전용 GFM 보기로 전환한다. **편집하기**로 돌아올 수 있다. 블록 전체를 선택해 지우면 해당 원문도 삭제되며, 실행 취소로 복원할 수 있다. ‘보존’은 내부 내용을 자동 변환하지 않는다는 뜻이다.

외부 앱에서 오른쪽으로 붙여 넣을 때는 텍스트를 사용한다. Markdown 원문을 해석하려면 왼쪽에 붙여 넣는다. 브라우저·워드의 HTML 서식을 자동으로 가져오지 않는다.

## 원문 보존 규칙

- 문서를 열기만 하거나 오른쪽에 포커스를 주기만 하면 원문을 변환하지 않는다.
- 수정하지 않은 블록의 `__굵게__`, 목록 기호, 빈 줄, 코드 언어, 표 정렬 등 원문 표현을 유지한다.
- 수정한 블록은 표준 Markdown으로 다시 작성한다. 예: `__내용__`이 `**내용**`으로 바뀔 수 있다.
- 여러 소스 줄에 걸친 일반 문단은 오른쪽에서 이어진 문장으로 보인다. 그 문단을 수정하면 하나의 소스 줄로 정리될 수 있다.
- 명시적 줄바꿈이나 복잡한 구문은 무리하게 단순화하지 않고 원문 보존 블록으로 처리한다.
- 기존 UTF-8 BOM·LF/CRLF 저장 정책, 파일 충돌 확인, 미저장 경고를 그대로 사용한다.

## 구현 구조

- `VisualMarkdownCodec`: Markdown을 Quill 문서로 해석하고 원문 블록별 범위를 기록한다. 실제 편집 위치를 따라 범위를 이동시켜 동일한 문장이 반복되어도 각 블록의 원문을 구분한다.
- `VisualEditorController`: 오른쪽 변경을 즉시 Markdown 저장 컨트롤러에 반영한다. 왼쪽 입력은 200ms 대기 후 오른쪽을 갱신한다. 오른쪽 자체 입력 시 편집 문서를 다시 만들지 않는다.
- `EditorController`: 양쪽의 저장·미저장 표시·실행 취소를 하나의 기록으로 관리한다. 한글 조합 중에는 서식 변경을 보류하고 하나의 조합을 하나의 취소 기록으로 묶는다.
- `VisualEditor`: Flutter Quill의 Windows 입력 연결을 사용한다. 원문 보존 블록은 기존 로컬 이미지·링크 정책을 적용한 렌더러로 표시한다.

추가 편집기 `flutter_quill`은 MIT 라이선스이며 API 변경 검토를 위해 11.6.0으로 고정했다. 원본·설치 스크립트는 계속 MIT다. 타사 구성 요소의 고지는 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)와 앱의 오픈소스 라이선스 화면을 따른다.

## 검증

`test/visual_markdown_codec_test.dart`, `test/visual_editor_test.dart`에서 원문 왕복, 중복 문단 보존, 인라인 서식, 목록, 문단 분리, 표 보존, 즉시 저장, 두 편집기의 실행 취소, Flutter 입력 연결의 한글 조합과 원격 요청 차단을 검사한다. 기존 파일 저장·경고·테마 테스트도 함께 실행한다.

실제 Windows 실행 확인과 자동 테스트 결과는 [v1.1 검증 기록](../verification/v1.1.0.md)에 구분해서 기록한다. 가상 IME 검증을 실제 두벌식 키보드의 모든 입력 상황을 검증한 것으로 간주하지 않는다.
