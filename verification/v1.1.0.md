## 양방향 편집에서 확인한 내용

- 오른쪽 Flutter 입력 연결로 제목을 수정하면 왼쪽 Markdown과 미저장 상태가 갱신된다.
- 오른쪽 수정 직후 별도 대기 없이 저장하면 최신 내용이 저장된다.
- Ctrl+Z / Ctrl+Y는 두 편집기에서 하나의 기록을 사용한다.
- 선택 영역에 툴바를 적용하면 마지막으로 선택한 편집기를 수정하고 포커스를 복원한다.
- 왼쪽 변경을 동기화한 뒤 오른쪽을 처음 클릭해도 포커스를 얻는다.
- 한글 조합 중 오른쪽 문서 객체를 교체하지 않고, 조합 전체를 한 번에 취소한다. 이는 Flutter 가상 IME 검증이다.
- 문서 전환 시 이전 동기화 예약과 실행 취소 기록이 새 문서에 섞이지 않는다.
- 수정하지 않은 중복 문단의 서로 다른 Markdown 표현, 표·코드·이미지 등 원문을 보존한다.
- HTML 엔티티·Unicode·겹치는 인라인 서식·목록·문단 분리·원문 보존 블록 삭제를 검사했다.
- 원격 이미지가 있는 오른쪽 편집 화면에서도 HTTP 클라이언트 생성 시도는 0회다.
- 기존 UTF-8/BOM/LF·CRLF, 실제 Windows 파일 잠금, 저장 오류·외부 변경·미저장 경고·테마 테스트를 함께 통과했다.

## 화면과 실제 Windows 확인 범위

- 실제 Windows Release 창을 실행하고 로컬 예제 파일이 양쪽에 표시되는 것을 확인했다.
- `01-two-way-light.png`는 실제 Windows 창의 캡처다.
- `02-edit-from-right.png`, `03-gfm-preview.png`, `04-two-way-dark.png`는 같은 Flutter 앱 위젯을 Windows 테스트 엔진에서 자동 입력·렌더링한 캡처다. 별도 목업이 아니다. 운영체제 제목 표시줄은 포함하지 않는다.
- 재현 명령: `flutter test tool/capture_screenshots_test.dart`. Windows 한글·Consolas 글꼴을 읽고 이미지를 생성한다.
- Windows 조작 중 사용자 입력이 감지되어 추가 키 입력 검증을 멈췄다. 실제 두벌식 키보드·네이티브 파일 선택·모든 DPI·접근성 환경의 전체 동작을 확인했다고 주장하지 않는다.
- 설치 마법사 버튼을 하나씩 누르는 수동 검증과 개발 도구가 없는 별도 PC에서의 실행 확인은 남아 있다. 설치·재설치·제거는 실제 Windows에서 자동 실행하여 검증했다.
- 설치 파일은 코드 서명되지 않았다. 자동 업데이트는 없다.

## 배포 형식

일반 사용자는 `LocalMarkdownEditor-Setup-1.1.0-x64.exe` 하나로 설치한다. 앱 로컬의 Microsoft x64 release CRT, 라이선스 고지, 사용 안내, 예제 문서를 포함한다. 개발용 소스는 태그 v1.1.0 및 소스 ZIP으로 제공한다. 지원·원문 보존 범위는 [양방향 편집 안내](../docs/bidirectional-editing.md)를 따른다.
